# Product Requirements Document: Project OrbitMentor

## 1. Product Overview
**Project OrbitMentor** is an AI-powered platform tailored for final-year engineering and computer science students. It bridges the gap between raw student skills and production-grade system design by offering two core modes: an automated **Idea Generator** (producing scoped concepts across three complexity tiers) and a tactical **Project Mentor** (delivering deep architecture, tech stack justification, and execution timelines).

## 2. Target Audience
- Final-year undergraduate students seeking capstone or thesis project architectures.
- Hackathon competitors needing immediate, viable system blueprints under strict time limits.

## 3. Core Functional Requirements
- **Dual-Mode Engine:** Toggle seamlessly between an Ideation engine and a Technical Mentorship engine.
- **Dynamic Chip & Search Inputs:** Multi-select skill chips and domain selection search bars.
- **Three-Tier Ideation:**
  - *Safe:* High feasibility, quick development cycle, standard production stacks.
  - *Applied ML:* Integrates modern machine learning pipelines, Retrieval-Augmented Generation (RAG), or agentic workflows.
  - *Super (Moonshot):* Research-grade, enterprise-scale complexity tailored for journal publication or deep-tech funding.
- **Mentor Blueprints:** Deep-dive outputs providing:
  - Optimal Tech Stack Rationale (comparative analysis).
  - 16-Week Final-Year Execution Roadmap.
  - Modular System Breakdown (microservices or component architecture).
